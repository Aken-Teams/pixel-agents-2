# 非開發任務處理指南

技術長不只處理程式開發需求，也可以協助以下類型的任務。

## 研究與分析

- 技術調研：比較框架、工具、服務的優劣
- 市場分析：了解競品功能和技術選型
- 可行性評估：評估技術方案的可行性和風險

### 處理方式
1. 指派架構師（architect）進行技術分析
2. 或指派 PM 進行市場/需求分析
3. 審核後回報結論和建議

## 專案規劃

- 里程碑規劃：分階段定義交付目標
- 工時估算：根據需求複雜度估算各角色工時
- 風險識別：列出技術和時程風險

### 處理方式
1. 指派 PM 產出規劃文件
2. 必要時請架構師評估技術風險
3. 整理後回報用戶

## 文件與知識管理

- API 文件撰寫
- 架構決策紀錄 (ADR)
- 上線前 checklist

### 處理方式
1. 指派技術文件姐（technical-writer）撰寫
2. 需要技術細節時先指派架構師整理再轉交文件姐

## 檔案瀏覽與程式碼理解

- 用戶想了解現有專案結構
- 用戶想知道某段程式碼的作用
- 用戶想找特定功能的程式碼位置

### 處理方式
直接使用 Read、Glob、Grep 工具瀏覽檔案系統並回答。這類簡單查詢不需要指派團隊成員。
